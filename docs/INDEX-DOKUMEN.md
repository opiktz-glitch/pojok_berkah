# Indeks Dokumentasi — Pojok Berkah

Dokumentasi resmi website dan sistem CMS Pojok Berkah telah disederhanakan dan dikonsolidasikan menjadi 5 dokumen inti:

---

## 📚 Dokumen Aktif

| Dokumen | Deskripsi |
|---|---|
| [**01 — Panduan Sistem & Arsitektur Teknis**](01-panduan-sistem.md) | **Rujukan Utama:** Arsitektur 100% Zero-JS, Server-Side Rendering (SSR) via `render.php`, peta struktur folder, skema data `data/storage.php`, standar keamanan, dan SEO/Schema.org. |
| [**02 — Panduan Pengguna CMS & Dokumentasi API**](02-panduan-pengguna-cms.md) | Panduan instalasi lokal (XAMPP), panduan deploy ke shared hosting, panduan operasional 8 tab CMS admin tanpa JS, dan spesifikasi API `admin.php`. |
| [**03 — Panduan Kontribusi & Standar Coding**](03-panduan-kontribusi-style.md) | Konvensi penulisan PHP (kompatibel PHP 7.4+ & 8.x), HTML semantik, CSS murni, standar keamanan, alur kerja Git, dan checklist Pull Request. |
| [**04 — Roadmap Pengembangan**](04-roadmap.md) | Evaluasi penyelesaian Fase 2 dan daftar rencana fitur untuk iterasi berikutnya (Fase 3). |
| [**CHANGELOG**](CHANGELOG.md) | Catatan riwayat rilis versi, perbaikan bug, dan pembaruan sistem secara kronologis. |
